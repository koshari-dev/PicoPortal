# PicoPortal – Workshop Manual Mobile

An offline-capable, mobile-friendly workshop manual and parts reference.

## Features

- Mobile-friendly web application.
- Installable Progressive Web App (PWA).
- Android compatibility through supported mobile browsers.
- Offline access to locally installed workshop content.
- Publication and manual hierarchy navigation.
- Parts catalogue lookup.
- Workshop procedure lookup.
- Search across indexed manual content.
- Python-based content extraction and indexing tools.

## Installation

1. Download the latest Workshop Manual Mobile release.
2. Extract the ZIP archive.
3. Open the application using its supplied launcher or local web server.
4. On Android, open the application in Chrome and use
   "Add to Home screen" where supported.

## Development

Application source is located in `viewer/`.

Content extraction and indexing tools are located in `tools/`.

The extracted workshop content and generated indexes are distributed
separately from this source repository.

## Compatibility

Designed for modern desktop and mobile browsers, including Android
Chrome.
